# Demo script
1. **Safe state:** click *Load safe sample*. Point out Available, Need, the SAFE badge and the safe sequence P1 → P3 → P4 → P0 → P2.
2. **Granted request:** P1 requests 1 0 2 and press *Request*. Use the graph's Before/After buttons to show the allocation edge appear.
3. **Unsafe request denied:** P0 requests 0 2 0. It is denied as unsafe and rolled back. Explain avoidance.
4. **Wait:** P4 requests 3 3 0. It must wait (not enough Available).
5. **Deadlock:** click *Load deadlock sample*. Show the red processes, the circular wait in the graph, and the Four Conditions panel (all PRESENT).
6. **Recovery:** click *Recover*. Show the victim terminated, resources released, and the badge changing. Mention preempt as the alternative.
7. **Close:** show utilization bars and the log.
